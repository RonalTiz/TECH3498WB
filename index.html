IT Computer Security (TECH 3498) explores comprehensive strategies, technical protocols, and architectural models designed to safeguard information systems, networks, and data assets from unauthorized access, disruption, and cyber threats.

Key Course Focus Areas
  • Fundamental Security Architecture: Confidentiality, Integrity, Availability (CIA triad), authentication, and authorization models.
  • Network Security & Perimeter Defense: Firewall architectures, IDS/IPS configuration, VLAN segmentation, and packet inspection.
  • Cryptography & PKI: Symmetric and asymmetric encryption, digital signatures, hashing algorithms, and SSL/TLS implementations.
  • Threat Analysis & Vulnerability Management: Vulnerability scanning, risk assessments, CVE cataloging, and mitigation planning.

PRO TIP
Cybersecurity Tip of the Day

Enforce Multi-Factor Authentication (MFA) & Use a Password Manager: Over 80% of data breaches involve compromised or reused passwords. Enabling MFA (preferably using an authenticator app or hardware FIDO2 key rather than SMS) blocks more than 99% of bulk automated credential attacks according to CISA and Microsoft threat intelligence. Pair this with unique, generated 16+ character passphrases for every account.
