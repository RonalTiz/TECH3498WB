Network Configuration and Connectivity

This report covers local name resolution, active network connections, and IPv6 interface and packet-capture observations. Fill in bracketed fields with results from the computer used for the lab.

Before submitting: System addresses, DNS servers, active connections, and packet captures vary by device and network. The IPv6 prefix 2001:db8::/32 is reserved for documentation and is not a public address for normal Internet use.

Lab 2.1 - Name resolution

Lab A - Localhost and the hosts file

Question or observationResponse

What does ping 127.0.0.1 test?It sends packets to the IPv4 loopback address, testing the local TCP/IP stack without sending traffic to another computer.
What command can ping ::1 on older macOS?Use ping6 ::1 where the system does not accept ping ::1.
Are the IPv4 and IPv6 loopback results the same? Why?They should both confirm local loopback connectivity, but they use different protocol families and addresses. The output format and timing can differ.
How does the computer know what localhost means?localhost is a reserved hostname resolved locally, commonly through the hosts file, to loopback addresses such as 127.0.0.1 and ::1.
What entries may already be in the hosts file?Typical entries map localhost to 127.0.0.1 and ::1. The exact comments and entries vary by operating system.
Why are some lines commented out?Lines beginning with a comment marker (usually #) are explanatory notes or disabled entries. The resolver ignores them.
What should ping me and ping winserv show after adding the mappings?Each name should resolve to the IP address assigned to it in the hosts file. me should resolve to the computer's address; winserv should resolve to the chosen gateway address. Replies depend on network settings and firewall behavior.
How could hosts-file name resolution be abused?A changed mapping could send a user to an unintended IP address when they enter a familiar hostname. Editing the protected system hosts file normally requires elevated permission, so an attacker would need an elevated process, a misconfiguration, or another way to alter name resolution.
What does ipconfig /displaydns show?It displays cached DNS client records, which can include recently resolved names and their associated data and time-to-live values. The cache contents depend on recent activity.

Question or observationResponse
Which interactive nslookup command displays the current DNS server?Enter server without an argument to display the current default DNS server in common interactive nslookup implementations.
What is netstat used for?It reports network connections and, depending on the options, listening ports, routing information, and interface statistics.
Which option helps identify the process using a connection?On Windows, netstat -o includes the process ID (PID); netstat -b can show the executable and may require elevated permissions. On macOS, lsof -iTCP lists TCP sockets and associated processes.
